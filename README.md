# Web Development Projects

This repository contains a collection of web development projects completed as part of my learning journey.

## Projects Overview

### 1. To-Do Web App
- **Objective**: Build a functional task management application to track pending and completed tasks.
- **Steps Performed**: 
  - Designed a responsive UI with HTML and CSS.
  - Implemented task addition, completion, editing, and deletion logic using JavaScript.
  - Added task categorization into 'Pending' and 'Completed' lists.
- **Tools Used**: HTML5, CSS3, JavaScript.
- **Outcome**: A responsive, interactive To-Do application with real-time task tracking.

### 2. Login & Authentication System
- **Objective**: Create a secure user authentication flow including registration and a personalized dashboard.
- **Steps Performed**:
  - Developed registration and login interfaces.
  - Implemented client-side validation and authentication logic.
  - Created a protected dashboard page accessible only after successful login.
- **Tools Used**: HTML5, CSS3, JavaScript.
- **Outcome**: A fully functional authentication system demonstrating user session management.

### 3. Web Calculator
- **Objective**: Develop a digital calculator capable of performing basic arithmetic operations.
- **Steps Performed**:
  - Built a grid-based calculator layout.
  - Implemented calculation logic to handle addition, subtraction, multiplication, and division.
  - Added clear and delete functionalities.
- **Tools Used**: HTML5, CSS3, JavaScript.
- **Outcome**: A clean, operational calculator with a user-friendly interface.

### 4. Tribute Page
- **Objective**: Create a static informational page dedicated to a significant person.
- **Steps Performed**:
  - Structured content using semantic HTML.
  - Styled the layout for readability and visual appeal.
  - Integrated images and lists to present a chronological timeline.
- **Tools Used**: HTML5, CSS3.
- **Outcome**: A professionally styled tribute page showing a biographical overview.

## General Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript
- **Styling**: Responsive Design, CSS Grid, Flexbox
